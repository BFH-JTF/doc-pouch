# Group / Department owned documents

Currently, a document can only be owned by a user.

I would like a document owner to be able to share ownership on the group or department level.

If they would do this, every user sharing group or department with the document owner would be treated as document owner.

I assume this needs adjustments in document types and the API.

Ensure that the new attributes are reflected in the access control within NeDbWrapper.ts

Update the API documentation in docpouch_openAPI.yaml and the rest of the documentation.
